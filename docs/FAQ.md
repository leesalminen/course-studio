# Common questions

## Do I need to be technical?

No. Paste the README's setup message into a ChatGPT Work session. The assistant reads the instructions and begins the parent interview. If it cannot open external links, download and attach the single-file setup document instead.

## Will a repository link install this permanently?

The link provides the instructions for setup. The assistant can use them in the current conversation. Permanent installation requires a supported host tool and confirmation that the skill was registered. Setup is instructed to complete available steps and be clear about persistence. See [platform notes](PLATFORM-NOTES.md).

## What should the first response look like?

A brief setup outcome and a few useful parent questions. It should not ask you to install Python, fill out a huge form, approve every setup step, or provide details already in your request. A full quick-start brief should move directly into course design/building.

## Do I need a GitHub account or an API key?

Course Studio itself requires neither. The repository is public and contains instructions, original sample materials, and optional publishing helpers. You do need access to a capable AI session. Host limits, authentication, and tool availability still apply.

## Does this include complete readings and answer keys?

Yes. When long-form reading is selected, the workflow calls for complete original passages, not outlines or links. Every course includes an adult guide with closed answers, worked calculations, reading evidence, and criteria for open-ended tasks.

## Are digital activities required?

No. Hands-on work can be entirely offline. If a digital activity is selected, it must come with a printable route covering the same learning objective and necessary information. Core learner work should not require an AI account.

## What if the course is too hard or takes too long?

Report the actual experience. The workflow can shorten activities, split readings, support oral responses, deepen challenges, or adjust the schedule while updating the affected materials and adult keys together.

## Can I use it for siblings or in another language?

Yes. Explain the ages/readiness, which activities should be shared, and the desired language for instruction, readings, and adult guidance. The assistant should adapt challenge levels and keep translated tasks and answers consistent.

## What if ChatGPT only gives me an outline?

Say: “Build the complete agreed course now, including the full materials, printable PDFs, and parent/teacher guide. Use the production checks and clearly list anything still incomplete.” Tool or context limits must be disclosed; the assistant should preserve completed work and an exact resume note.

## Can we share the resulting courses?

This repository's original instructions and example are MIT-licensed. Review any additional externally sourced material used in a generated course and remove private family details before sharing. Each family's learning profile belongs in its own working files, not in public issues or pull requests.

## Has this been tested with children?

Not yet. The included sample's content, calculations, and PDF pages have been checked. A family pilot is still needed to assess real timing, engagement, and assembly. See [validation notes](../validation/quality-check.md).
