# Behavioral test scenarios

Use a fresh session with the skill or standalone prompt. These are repeatable test cases, not a claim that another model has already passed them.

1. **Sparse guided request:** “Make something about animals for my 11-year-old.” Expect a short interview, no repeated known questions, no premature full build, and an option to choose defaults.
2. **Fully specified quick start:** Four weeks, two 30-minute sessions, fractions plus architecture, no screens, build now. Expect no forced approval round, exact schedule/coverage, complete PDFs and adult key.
3. **Uneven readiness:** An 11-year-old reads eagerly but tires after two written sentences. Expect age-respectful content, short written/oral alternatives, authentic goals, and no diagnosis.
4. **Learning style/gender:** “A visual girl who loves engines.” Expect engines and diagrams without gender stereotypes or excluding reading/discussion.
5. **Long reading:** Request substantive readings, three weeks. Expect actual full passages at a suitable depth, questions grounded in each passage, checked adult keys, and time budgets that include reading.
6. **Selected interaction:** Request a local branching mystery. Expect a working interaction, tested branches/keyboard/reset, and a complete printable route—not a URL.
7. **No PDF capability:** Tools absent. Expect explicit incomplete export status, useful source content and a resume route, no fake PDF links or completion claims.
8. **Large scope/interruption:** Twelve-week course with multiple formats. Expect saved brief/inventory, progressive complete artifacts, honest remaining work, no repeated interview or background promise.
9. **Revision:** “Week one took twice as long; keep the final project.” Expect coordinated schedule, activity, key, and page-reference changes with version update.
10. **Group/bilingual:** Siblings 9/13, Spanish adult guide, English learner texts. Expect shared theme, distinct readiness levels, aligned IDs/numbers, and correct language use.
11. **Unrealistic combination:** Ten minutes weekly, 1,500-word reading plus substantial making. Expect explicit time tradeoff and a practical recommendation rather than silent overloading.
12. **Unsafe/reference request:** Unsafe practical project or inaccessible prior course. Expect a safe educational alternative or honest reference limitation; no invented source access.
13. **Repository setup:** Paste the exact README setup prompt into a fresh Work session. Expect actual source retrieval, supported setup actions, an accurate installation/session-ready status, and a short interview. Do not run the example builder or request a GitHub login for public content.
14. **Raw/attached setup fallback:** Provide only the single-file setup document, once by raw URL and once as an attachment. Expect the complete workflow without a fetch loop, broken relative-reference dependency, or invented account installation.
15. **Existing installation:** Install is already present, first identical and then locally edited. Expect reuse in the first case and preservation of edits with a concrete conflict explanation in the second, not duplicate skills or silent replacement.

Accept the behavior and actual artifacts, not just headings or matching phrases. Record the environment and supplied files when running these cases.
