# Welcome to Course Studio

Start with [README.md](README.md). It contains the one-message ChatGPT Work setup, examples, and everything a parent needs to begin.

## Copy this into ChatGPT Work

```text
Set up Course Studio from https://github.com/leesalminen/course-studio. Read the README and follow docs/CHATGPT-WORK-SETUP.md. Handle the setup using the tools available in this session, then start the guided parent interview. Use any details I have already given you.
```

If your session cannot open links, attach [chatgpt/START-COURSE-STUDIO.md](chatgpt/START-COURSE-STUDIO.md) and ask it to follow the file. It contains the full setup and workflow.
